# Слой доработок платформы

Собранные страницы (`platform/index.html` и лёгкие страницы учеников `platform/s-*.html`) получают поверх сборки
небольшой слой доработок. Он хранится здесь, в репозитории, и накладывается одной командой:

```
python3 tools/apply.py --tts <папка Kokoro>     # с дозаписью недостающей озвучки
python3 tools/apply.py --no-audio               # только скрипты, стили и данные
```

Повторный запуск безопасен: всё вставляется между метками `<!--iris-patch:start-->` / `<!--iris-patch:end-->`
и заменяется целиком. После полной пересборки платформы команду нужно запустить ещё раз.

| Файл | Что делает |
|---|---|
| `patches/explain.js` | «Почему не так»: правила для типичных ошибок (формы глагола, времена и их маркеры, артикли, предлоги, порядок слов, -s, сравнения, похожие слова, опечатки) |
| `patches/review.js` | объяснение под ошибкой в упражнении + «🔁 Работа над ошибками»: повтор сразу, через 1, 3 и 7 дней |
| `patches/goal.js` | «🎯 Моя цель»: для чего английский (учёба / работа / … + сфера), слова под цель, тренировка; цель уходит преподавателю с ответами |
| `patches/ipa.js` | транскрипция в «Моём словаре», переводчике и на карточках слов |
| `patches/patch.css` | стили всего перечисленного |
| `data/packs.py` | цели, сферы и наборы слов (25 сфер × 20 слов с примерами) |
| `data/ipa.json` | таблица транскрипций (ipa-dict en_UK, MIT; пропуски — espeak-ng), приведённая к словарной записи |
| `voice/harvest.py` | находит всё, что могут произнести игры и кнопки 🔊, и показывает фразы без записи |
| `voice/render.py` | дозаписывает фразы тем же голосом, что и вся платформа (Kokoro `bf_emma`) |

Данные ученика (цель, очередь повторения, прогресс слов) лежат в `fields` профиля под ключами
`iris-goal`, `iris-rv`, `iris-packs` — поэтому синхронизируются между устройствами ученика.

Озвучка: Kokoro-82M (Apache-2.0), модель `kokoro-v1.0.onnx` и `voices-v1.0.bin` из релизов kokoro-onnx,
`pip install kokoro-onnx soundfile` в `venv/` внутри той же папки.

Проверка: `IRIS_TOKEN=<код ученика> node tools/tests/test-patches.js` при запущенном
`python3 -m http.server 8765` в корне репозитория (серверы синхронизации в тесте заблокированы).
