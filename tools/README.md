# Слой доработок платформы

Собранные страницы (`platform/index.html` и лёгкие страницы учеников `platform/s-*.html`) получают поверх сборки
небольшой слой доработок. Он хранится здесь, в репозитории, и накладывается одной командой:

```
python3 tools/apply.py --tts <папка Kokoro>     # с дозаписью недостающей озвучки
python3 tools/apply.py --no-audio               # только скрипты, стили и данные
```

Повторный запуск безопасен: всё вставляется между метками `<!--iris-patch:start-->` / `<!--iris-patch:end-->`
и заменяется целиком. После полной пересборки платформы команду нужно запустить ещё раз.

| Файл | Что делает |
|---|---|
| `patches/explain.js` | «Почему не так»: правила для типичных ошибок (формы глагола, времена и их маркеры, артикли, предлоги, порядок слов, -s, сравнения, похожие слова, опечатки) |
| `patches/review.js` | объяснение под ошибкой в упражнении + «🔁 Работа над ошибками»: повтор сразу, через 1, 3 и 7 дней |
| `patches/goal.js` | «🎯 Моя цель»: для чего английский (учёба / работа / … + сфера), слова под цель, тренировка; цель уходит преподавателю с ответами |
| `patches/ipa.js` | транскрипция в «Моём словаре», переводчике и на карточках слов |
| `patches/patch.css` | стили всего перечисленного |
| `data/packs.py` | цели, сферы и наборы слов (25 сфер × 20 слов с примерами) |
| `data/ipa.json` | таблица транскрипций (ipa-dict en_UK, MIT; пропуски — espeak-ng), приведённая к словарной записи |
| `voice/harvest.py` | находит всё, что могут произнести игры и кнопки 🔊, и показывает фразы без записи |
| `voice/render.py` | дозаписывает фразы тем же голосом, что и вся платформа (Kokoro `bf_emma`) |

Данные ученика (цель, очередь повторения, прогресс слов) лежат в `fields` профиля под ключами
`iris-goal`, `iris-rv`, `iris-packs` — поэтому синхронизируются между устройствами ученика.

Озвучка: Kokoro-82M (Apache-2.0), модель `kokoro-v1.0.onnx` и `voices-v1.0.bin` из релизов kokoro-onnx,
`pip install kokoro-onnx soundfile` в `venv/` внутри той же папки.

Проверка: `IRIS_TOKEN=<код ученика> node tools/tests/test-patches.js` при запущенном
`python3 -m http.server 8765` в корне репозитория (серверы синхронизации в тесте заблокированы).

## Пункты аудита (ноябрь 2026)

| Пункт | Что сделано |
|---|---|
| 1–2. Прогресс только в браузере, ответы через бесплатные серверы | `platform/api/box.php` — свой «почтовый ящик» на хостинге (обычный PHP, без базы). Хранит последние зашифрованные сообщения (ответы, прогресс, комментарии); прочитать их ящик не может. В страницах он подключён первым «сервером связи» (`patches/early/box-client.js`), живой урок по-прежнему идёт через серверы связи. Пока PHP на хостинге не работает, ящик просто молчит |
| 3. Нет офлайн-режима | `platform/sw.js` + `patches/offline.js`: страница и картинки открываются без связи, ответы досылаются, когда связь вернулась |
| 4. Тяжёлая страница | в личной странице — только записи её уроков (минус ~1 700 строк списка записей) |
| 5. Имена всех учеников | в личной странице — только своя запись доступа и своё имя в меню |
| 6. Ключ в адресе | после входа код убирается из адресной строки (во встроенных браузерах мессенджеров остаётся — оттуда открывают «в Safari») |
| 7. Перевод | понятное сообщение, если онлайн-перевод не ответил; основной путь — встроенный словарь |

Проверка ящика: `php -S localhost:8767 -t .` и `IRIS_TOKEN=… IRIS_TEACHER=… IRIS_BASE=http://localhost:8767/platform/index.html node tools/tests/test-audit.js`.

## 🔒 Уроки только по личной ссылке, общий код — отдельными файлами

`tools/seal.py` (вызывается из `apply.py` последним шагом):
- панели уроков каждого ученика сжимаются и шифруются (AES-GCM) его ключом. Ключ открывается только его
  личной ссылкой и ссылкой преподавателя. Без ссылки страница показывает только вход, а в коде страницы
  текста уроков нет;
- большие скрипты, стили и общие словари выносятся в `platform/assets/app-<хэш>.*`. Браузер скачивает их один
  раз и хранит год (имя меняется вместе с содержимым), а личная страница весит ~300–500 КБ вместо ~2 МБ;
- загрузчик (`patches/loader.js`) открывает уроки и запускает платформу.

Для `apply.py` теперь нужен код преподавателя: `IRIS_SECRET=<код> python3 tools/apply.py …` или
`--secret-file <файл вне репозитория>`. Без кода скрипт откажется работать: иначе уроки нельзя ни открыть, ни зашифровать заново.
Проверка: `tools/tests/test-privacy.js`.
